# Opening titles

`intro.html` is the first forty seconds of the demo video, built to be screen-recorded while the
narration in [`../demo-video-script.md`](../demo-video-script.md) beat 1 is read over it.

It is one file. Open it in a browser and record.

## Running it

    open docs/intro/intro.html

Three.js loads from a CDN, so the first open needs a network connection; after that the browser has it
cached. If you would rather not depend on that during a take, load it once beforehand and leave the tab
open.

| key | |
|---|---|
| `H` | hide the controls — **press this before recording** |
| `F` | fullscreen |
| `SPACE` | play / pause |
| `R` | restart from zero |
| `←` `→` | jump between the three acts |

## What it is doing

Three acts, matching the three things the pitch has to cover, in the order the script says them.

**Act one — why it matters (0–13s).** Six hundred homes on a street grid. The colour is the condition:
cool at first, reddening as the heat builds. Then sixty-nine of them go out. That is the number
Multnomah County recorded, not a number chosen because it looked right, and the ones that go out are
drawn from the isolated homes, because that is who it happened to.

**Act two — the problem (13–26s).** One home stays lit: the volunteer. They reach out to one neighbour,
then another, roughly one a second, which is slow on purpose — it is the rate a person actually works.
The counter climbs toward 1,942, the checks New York City's Be a Buddy programme made by hand.

**Act three — who it is for (26–40s).** The same volunteer, now reaching everyone at once, and the porch
lights come on across the neighbourhood.

Every figure on screen is in [`../sources.md`](../sources.md). Do not add one that is not.

## Recording notes

- Record the browser window, not the whole screen: the stage is a fixed 16:9 box so the framing is the
  same whatever the window size.
- Keep the tab focused. Browsers stop animating a hidden tab, so alt-tabbing mid-take freezes it.
- Read the narration over a single unbroken play. The act timings are set to the script's pacing, so if
  you are running long, pause on act three rather than speeding the whole thing up.
